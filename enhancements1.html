Enhancements 01

Overview

This page describes the HTML and CSS enhancements applied to the website beyond the basic assignment requirements. These enhancements improve the visual appearance, usability, and overall user experience of the website. A maximum of 2 enhancements are submitted for marking.

Enhancement 1: Background Video with Overlay

How it goes beyond the basic requirements: The assignment specification requires a background graphic on index.html using CSS. This enhancement goes beyond that by implementing a looping background video on all pages, with a semi-transparent dark overlay to ensure text remains readable.

Code needed to implement the feature: A <div class="backgroundvideo"> contains an HTML5 <video> element with autoplay muted loop playsinline attributes. The CSS positions the container with position: fixed; z-index: -2; width: 100%; height: 100%; so it sits behind all other content. An additional .video-overlay div uses background: rgba(0,0,0,0.6) to darken the video for readability.

This can be seen on all pages including the Home Page and Topic Page.

Enhancement 2: Active Navigation Highlight and Hover Transitions

How it goes beyond the basic requirements: The specification requires a menu with a background colour. This enhancement adds an .active CSS class that visually highlights the current page in the navigation menu, and uses CSS transition and :hover pseudo-class effects so links animate smoothly when hovered. This improves navigation usability.

Code needed to implement the feature: In CSS, nav ul li a.active applies a highlighted colour and underline to the active page link. The :hover rule uses transition: 0.3s for smooth colour change. In PHP pages, the $active_page variable is used in menu.inc to apply the class dynamically.

This enhancement is visible on all pages via the navigation bar. Source reference: CSS transitions — MDN Web Docs.

Other Improvements

Additional improvements made to the website include: consistent YouTube video hyperlink on the home page, improved typography with readable fonts and spacing, styled figure/caption on the topic page, and responsive flexible layout using percentage-based widths.
