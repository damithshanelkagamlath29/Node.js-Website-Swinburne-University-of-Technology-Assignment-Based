# Node.js Assignment Project

## Project Overview

This repository contains a fully functional Node.js web application developed as part of a Swinburne University of Technology assignment. The project was completed through collaborative group work, covering system design, development, testing, and implementation.

The application demonstrates modern web development practices using Node.js and follows the assignment requirements and specifications provided by Swinburne University of Technology.
